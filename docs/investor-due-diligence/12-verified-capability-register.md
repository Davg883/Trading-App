## 1. Purpose and Classification Taxonomy

This register reconciles every material finding from the Claude Opus independent technical review ([`opus-independent-technical-review.md`](file:///c:/GPT%205%20CODEX/Trading%20app/docs/investor-due-diligence/opus-independent-technical-review.md), [`opus-investor-red-flags-and-mitigations.md`](file:///c:/GPT%205%20CODEX/Trading%20app/docs/investor-due-diligence/opus-investor-red-flags-and-mitigations.md), and [`10-technical-evidence-register.md`](file:///c:/GPT%205%20CODEX/Trading%20app/docs/investor-due-diligence/10-technical-evidence-register.md)) against direct source-code inspection, test execution, and live non-destructive endpoint observation.

Each item is classified into one of six strict states:

1. **`CONFIRMED_FINDING`** — Verified in source code, configuration, or session records as an accurate defect or architectural gap requiring remediation.
2. **`PARTIAL_OR_OVERSTATED_FINDING` (Nuanced / Partial False Positive)** — The underlying code path exists, but the severity, exploitability, or scope described in the review requires technical qualification based on actual code inspection.
3. **`FALSE_POSITIVE`** — Claimed defect is contradicted by actual source code or runtime semantics.
4. **`CORRECTED_DEFECT_LOCAL`** — Defect has been fixed and verified locally in tests, awaiting owner-authorised production deployment.
5. **`PRODUCTION_VERIFIED_FIX`** — Defect has been fixed, deployed, and verified against the live production environment (`https://capital.aiguides.co.uk` or GitHub Actions).
6. **`INDEPENDENT_VERIFICATION_REQUIRED`** — Cannot be closed by AI or founder self-attestation; requires a qualified human professional (solicitor, FCA regulatory adviser, CREST penetration tester, or independent engineer with console access).
